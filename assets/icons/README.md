# Иконки TRDS

`catalog.js` содержит 1 065 исходных SVG из страницы Icons файла Figma `TDEt0QXn8xkQihCoXz4Jzx`, выгрузка 24 ноября 2026 года. Сохранены ID компонентов, полные имена и все 16 категорий. Первые 20 элементов расположены как в утверждённом макете Paper.

Геометрия и размер 24 × 24 сохранены. Синий цвет исходных векторов заменён на `currentColor`, чтобы иконки использовали цвет контекста. В браузере идентификаторы `clipPath` получают отдельный префикс для плитки и просмотра; исходный SVG для копирования остаётся самостоятельным файлом.

Данные подключаются обычным скриптом без внешних запросов и библиотек. На странице одновременно отрисовываются 20 иконок. Поиск и фильтры работают по всему каталогу, а не только по видимой странице.
