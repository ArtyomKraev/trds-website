# Сайт TRDS

Сайт дизайн-системы TRDS: главная, начало работы, работа с агентами, пять страниц раздела «Основы» и четыре страницы компонентов «Ввод и выбор», перенесённые из [Paper](https://app.paper.design/file/01M847SMXXTXQ990D316GT3206/p-3-0).

Обычные HTML, CSS и JavaScript. Устанавливать зависимости и запускать сборку не нужно. Скрипты рисуют декоративный фон, наклоняют карточки, раскрывают меню и переключают вкладки; тексты и ссылки работают без JavaScript.

## Запуск

Можно открыть `index.html` в браузере. Для работы удобнее локальный сервер — из папки проекта:

```sh
python3 -m http.server 8000
```

Открыть [localhost:8000](http://localhost:8000). После изменения файлов обновить страницу. Остановить сервер: `Ctrl+C` в терминале.

В HTML и CSS есть короткие комментарии по-русски. Общие стили лежат в `styles.css`, оформление и движение карточек — в `cards.css`.

Все страницы, включая 404, используют общее CSS-появление `page-enter`: шапка приходит сверху на 24 px, сайдбар слева на 32 px, контент снизу на 24 px. Движение длится 720 мс, короткое проявление — 160 мс; задержки блоков 0–300 мс. Движутся 5–8 крупных блоков, а не отдельные иконки каталога. Анимация не меняет размеры, не использует JS-цикл или постоянный `will-change`; после завершения не удерживает `transform`. При `prefers-reduced-motion: reduce` она отключена, при клавиатурном фокусе элемент показывается сразу. Повторная загрузка запускает появление заново; прокрутка его не запускает.

В боковом меню 13 компонентов: Dropdown включает Dropdown Item, Table объединяет ячейки, заголовки и строки, Text Fields — Text Field, Text Area и Code Field с Code Digit. Text Fields, Upload Zone, Selection и Toggle открывают страницы сайта. Остальные пункты пока ведут в существующую документацию репозитория ДС. Все названия левого меню на английском; язык контента и настроек примеров сохранён.

Кнопка очистки поиска использует исходный SVG `Icons/Signs/Times` (`81:1513`) из каталога ДС. Она появляется при непустом запросе, сохраняет текущую категорию и возвращает фокус в поле. Системный крестик браузера отключён.

## Как редактировать

- **Тексты и адреса:** в `index.html`, в тегах `h1`, `h2`, `p` и атрибутах `href`.
- **Цвета:** в переменных `:root` в начале `css/styles.css`. Это семантические цвета тёмной темы TRDS. Иллюстрации карточек встроены в HTML и используют те же токены. В отдельные SVG через `<img>` переменные страницы не наследуются.
- **Ширина страницы:** `--content-width`. Сейчас 1200 px, по 200 px с каждой стороны на экране 1600 px.
- **Кнопки-ссылки:** общий класс `.button`, варианты `.button--accent` и `.button--secondary`.
- **Карточки:** `css/cards.css`. Ссылка `.card` неподвижна, наклоняется только `.card__surface`. SVG `.card__art` имеет размер 387×208 px и прижат к нижнему краю, как в Paper.
- **Наклон:** `settings` в `js/cards.js`: угол 10°, глубина 14 px, жёсткость и затухание пружины. Перспектива 800 px задаётся в CSS.
- **Hover-графика:** у документа смещаются спутники и строки, у основ сближаются круги, у компонентов пульсируют контур и штрихи псевдотекста. Клавиатурный фокус запускает графику без наклона. На touch наведение не имитируется; `prefers-reduced-motion` отключает эффекты.
- **Сетка точек:** `js/dot-field.js`. В `settings` меняются шаг (`spacing`), размер (`radius`), цвет (`color`), яркость (`brightness`) и радиус реакции на мышь (`mouseReach`). `lightSources()` задаёт движение света, `draw()` — притяжение, возврат и отрисовку точек. CSS-класс `.dot-field` размещает canvas под контентом.
- **Мобильная версия:** медиазапросы в конце CSS. При ширине до 1088 px карточки идут в один столбец, до 640 px уменьшаются поля и заголовок. Эти адаптивные правила добавлены при переносе; отдельного мобильного макета пока нет.

Фон сделан по мотивам [Bencho](https://bencho.dev/): мелкая сетка с движущимися пятнами света, мягким притяжением к курсору, затухающим следом и короткой волной от клика. Это собственная реализация на Canvas 2D, без React и внешних библиотек. Canvas не перехватывает нажатия и скрыт от скринридеров. На сенсорных устройствах остаётся спокойное фоновое движение; `prefers-reduced-motion: reduce` отключает движение и взаимодействие, оставляя статичный рисунок. В скрытой вкладке и вне экрана цикл приостанавливается.

Классы вида `card__content` обозначают часть блока, а `button--secondary` — вариант блока. Это только соглашение об именовании, специальная библиотека не требуется.

- Тёмная тема, сетка, типографика и размеры настольного макета.

Карточка «Документация» открывает `getting-started.html`, а «Основы» — `typography.html`. Страница `agents.html` открывается из бокового меню документации и синей карточки ИИ на странице «Начало работы». Её блоки статичны: скрипт наклона не подключён. Пять кнопок копируют инструкцию и команды; результат показывается галочкой и сообщением. Карточка «Компоненты» открывает «Поля ввода». Разделы бокового меню образуют аккордеон с плавным раскрытием за 300 мс и поддержкой повторных кликов во время движения. С JavaScript закрытие соседей анимируется; без него работает нативное `name` у `details`. На телефоне общее меню свёрнуто при входе; без JavaScript оно остаётся открытым. Новые страницы подключайте относительными ссылками. Псевдокнопка со штрихами — декоративная часть SVG, а не отдельный интерактивный элемент.

## Компоненты · Ввод и выбор

Пять исходных экранов объединены в четыре страницы. Источник — [раздела Paper](https://app.paper.design/file/01M847SMXXTXQ990D316GT3206/p-3-0/HFK-0). Источник размеров, цветов, текста и SVG — живые JSX/computed styles от 24 ноября 2026. Скрытые экраны и пояснения под примерами не переносились. Code Field остаётся вкладкой в «Полях ввода». Selection Control и Selection Item объединены в `selection.html` с вкладками Control/Item; старые адреса переводят на нужную вкладку. Подписи Item не переносятся в две строки. Общая оболочка переиспользует docs.css; новые страницы подключают прежнее появление без отдельного цикла анимации.

Примеры используют нативные input/textarea, checkbox/radio и switch. Настройки справа меняют размер, состояние и значение. Реальный фокус отражается в Focused; после blur восстанавливается состояние, а ошибка сохраняется независимо от фокуса; «Сбросить» возвращает исходный макет. Вкладки поддерживают стрелки, Home и End. Email проверяется после выхода из поля. У Text Area есть ограничение 200 символов и счётчик; Code Field принимает шесть цифр, вставку полного кода, автозаполнение и переходы стрелками/Backspace. Код подтверждения демонстрационный: сервиса проверки нет. Error и Disabled можно включить в настройках. У Code Field нет оси размера; она скрывается на этой вкладке.

Upload Zone открывает системный выбор файлов, принимает drop и показывает выбранные имена с удалением. Файлы остаются в памяти вкладки; сетевой загрузки и чтения содержимого нет. Исходный M сохранён в размере утверждённого Paper (676 px по ширине), S — компактная зона 44 × 44, L — высотой 250 px. Строки файлов содержат SVG File из ДС, фактический размер и красную SVG Trash. Сброс очищает список. Изменения состояния и служебные сообщения доступны скринридеру.

При удалении файла видимые подписи и иконки распадаются справа налево на пыль, улетающую вверх за 950 ms. У красной корзины нейтрально-серый hover. Декоративный Canvas не задерживает удаление или фокус и не перехватывает клики. Место строки резервируется до завершения пыли, затем плавно схлопывается за 360 ms; это работает и для последнего файла, и для нескольких быстрых удалений. Частицы ограничены областью строки, поэтому не заходят на соседние файлы или зону загрузки. Добавление файлов тоже плавно перестраивает зону и проявляет новые строки. `js/upload-dust.js` подключён только в Upload Zone; Canvas/RAF очищаются по завершении, reset, resize, уходе со страницы и включении reduced motion. Одновременно работают не более трёх эффектов. При reduced motion удаление мгновенное. Снимок строится из видимых подписей и SVG ДС, содержимое фото не читается.

Toggle помещён в карточку 400 × 80 px с отступом 20 px, скруглением 20 px / superellipse(2) и небольшой двухслойной тенью (2/8 px при 8%, 1/2 px при 4%). Обычный border-radius остаётся запасным вариантом для браузеров без corner-shape. Сохранена пользовательская правка Paper: текст 18 px, расстояние от колокольчика 8 px. Иконки Bell/Bell Slash из ДС и switch меняют одно состояние; короткий звон проигрывается только при включении и отключается при reduced motion.

Цифры Code Field появляются сверху с мягким отскоком за 400 ms; вставка нескольких цифр даёт задержку 35 ms между ними. При удалении цифра уходит вверх за те же 400 ms: общий набор keyframes воспроизводится с direction: reverse, поэтому смещения, масштаб, отскок и easing точно зеркальны. Курсор скрыт до завершения ухода цифры; удаление во время появления разворачивает уже идущую анимацию с текущего кадра. Повторный ввод прерывает её уход, не задерживая значение поля. Декоративные aria-hidden слои не заменяют нативные поля: ввод, вставка, автозаполнение, фокус и Backspace работают как прежде. Пример направления — [Bencho One-time code](https://bencho.dev/blocks/one-time-code); реализация самостоятельная, без новых зависимостей и звука.

В Selection зафиксирована ширина отметки 24 px: SVG не меняет геометрию при выборе. Только в режиме «Одна строка», когда выбраны оба Checkbox во вкладке Item, строки падают вниз с небольшим отскоком и возвращаются через 1,8 секунды, сохраняя значения. Зачёркивание появляется исключительно на время падения и исчезает при возврате или отмене; обычный checked ничего не зачёркивает. В режиме «С пояснением» этих эффектов нет. Повторное взаимодействие, смена вкладки/настроек, resize и reset останавливают падение. Идея — [Bencho Checklist](https://bencho.dev/blocks/checklist). Анимации используют только transform; reduced motion отключает движение.

Во всех окнах предпросмотра постоянно видна сетка с шагом 20 px и базовой прозрачностью 10%. Мышь слегка подсвечивает и притягивает точки. Canvas использует RAF только при движении/затухании, останавливается при покое, уходе со страницы, blur, scroll и выходе из viewport. Reduced motion сохраняет статичные точки; без JS работает CSS radial-gradient. Исходная сетка главной и 404 не изменялась. В Paper обновлены навигация Selection, карточка Toggle, строки файлов и фоны всех сцен.

Мобильная компоновка добавлена при переносе: настройки переходят под пример, поля ужимаются по доступной ширине. Проверены 320/390/768/1024/1280/1600 px, мышь, клавиатура, все настройки, reset, ввод/вставка кода, выбор и drop нескольких файлов, reduced motion и отсутствие ошибок JavaScript. Временные выгрузки Paper, скриншоты и браузерные сценарии лежат в игнорируемой `.preview/`.

## Основы

Пустой результат поиска оформлен по утверждённому [варианту НЛО в Paper](https://app.paper.design/file/01M847SMXXTXQ990D316GT3206/p-3-0/C5B-0): оригинальный SVG 320 × 236, сообщение «Кажется, её похитили.» и сброс фильтров по центру всей статьи. Параллакс реагирует на мышь в области пустого состояния: тарелка смещается до 16 × 10 px, персонаж — до 10 × 7 px, звёзды — в противоположную сторону. Пружина плавно возвращает слои на место и останавливает requestAnimationFrame после успокоения. При возврате результатов, скрытии вкладки, прокрутке и выходе сцены из экрана цикл останавливается; на touch и при reduced motion иллюстрация статична. Геометрия исходного SVG сохранена, для движения добавлены обёртки групп.

Поиск иконок выделяется при фокусе изменением фона, без обводки. Меню дополнительных категорий раскрывается затухающей пружиной за 600 мс, пункты появляются каскадом; подсветка плавно перемещается между строками, выбранный пункт отмечен галочкой. Название и ширина кнопки меняются за 300–380 мс. Движение вдохновлено [Bencho Picker](https://bencho.dev/blocks/picker), реализовано на CSS и Web Animations API без зависимостей. Повторные клики продолжают движение из текущего положения; при `prefers-reduced-motion` переходы мгновенные.

- **Иконки:** 1 065 оригинальных SVG из Figma, 16 категорий, по 20 иконок на странице. Поиск по имени, категории и русским синонимам распространённых действий. Выбор обновляет просмотр и ссылку на исходный компонент; кнопки копируют самостоятельный SVG 24 × 24 с `currentColor` и полное имя из библиотеки. На телефоне выбор переводит к просмотру, кнопка «К каталогу» возвращает к выбранной плитке. Без JavaScript доступны первые 20 образцов со ссылками в Figma; при отказе буфера обмена появляется поле для ручного копирования. Источник данных описан в `assets/icons/README.md`.
- **Типографика:** восемь стилей из Paper. На узком экране метаданные располагаются над примером; размер самого примера сохраняется.
- **Цвета:** переключатель меняет палитру, HEX-подписи и оформление текущей страницы. Светлые значения взяты из `trds-agent-ready/data/tokens-resolved.json`, коллекция `Semantics`, режим `Light`. На другие страницы выбор не переносится. Значения образцов хранятся в `colors.html`, семантические переменные — в `css/foundation-themes.css`.
- **Сетки:** три вкладки, в каждой две схемы — с навигацией и без неё. SVG перенесены из Paper. Верхняя панель зелёная, боковая и нижняя — оранжевые. Размеры под схемами — обычный текст; число и `px` одного цвета.
- **Отступы:** восемь значений от 4 до 64 px и семь вариантов скругления, включая Full. Образцы сохраняют размеры, ряды переносятся по ширине статьи.

Вкладки поддерживают мышь, Tab, стрелки, Home, End, Enter и пробел. Без JavaScript все панели доступны последовательно, а ссылки вкладок ведут к разделам. Основы используют существующие шапку, футер и боковое меню, без анимации наклона. Шрифты загружаются локально; для чисел добавлен Roboto Medium 500.

Активная линия вкладок скользит за 340 мс. В сетках обе плитки переворачиваются вокруг вертикальной оси: 220 мс до ребра и 360 мс до раскрытия новой схемы. Подписи появляются с небольшим горизонтальным сдвигом. Повторные клики объединяются в последний запрос, не обрывая поворот; изменение ширины завершает переход в выбранное состояние. В палитре новая тема раскрывается круговой волной от точных координат клика за 820 мс: маска постепенно меняет фон, меню, текст и образцы. При управлении с клавиатуры волна начинается в центре выбранного таба. Используется View Transitions API; без него остаётся затухание и сдвиг. При `prefers-reduced-motion` переключение мгновенное. Поведение находится в `js/tabs.js`, оформление линии — в `css/foundations.css`.

## GitHub Pages

Сайт опубликован: [artyomkraev.github.io/trds-website](https://artyomkraev.github.io/trds-website/).

Pages настроен на **Deploy from a branch → main → /(root)**. После отправки изменений в `main` GitHub автоматически обновляет сайт; статус публикации виден во вкладке **Actions** репозитория. Локальные изменения появятся на сайте только после коммита и `git push`.

Все локальные пути относительные, поэтому страница работает и под `/trds-website/`.

[Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Для CSS и JavaScript в HTML задан параметр версии, чтобы после обновления браузер не смешивал новый HTML со старыми ресурсами. Для оформления основ и вкладок — `?v=20261124-theme-reveal`. При изменении общих стилей обновляйте версию на всех страницах.

## Проверка

При первоначальном переносе проверены настольная и мобильная раскладки в браузере, отсутствие горизонтального переполнения, загрузка графики и ошибки консоли. После изменений достаточно снова открыть страницу, проверить широкий и узкий экран, пройти ссылки клавишей Tab.

Roboto распространяется по Apache License 2.0, Roboto Flex и Roboto Mono — по SIL Open Font License 1.1. Тексты лицензий сохранены рядом со шрифтами. Отдельная лицензия на код и дизайн проекта пока не выбрана.

В документации карточки используют общий `js/cards.js`: у серых ресурсов угол 4° и глубина 6 px, у горизонтального блока ИИ — 2° и 3 px. Параметры задаются через `data-tilt` и `data-depth`; главная сохраняет 10° и 14 px. Иллюстрация «Сборка» перенесена из Paper: детали соединяются на ховере или клавиатурном фокусе, при уходе возвращаются назад. Верхние ссылки Figma → GitHub используют Link / Accent / S, стрелки 12 px и синее подчёркивание Accent/Fill, которое раскрывается слева направо. При `prefers-reduced-motion` движение отключено.

Страница агентов проверена при ширине 1600, 390 и 320 px: без горизонтального переполнения. Проверено точное копирование инструкции и всех четырёх команд, включая кавычки JSON. Подсветка размечена обычными `span`, библиотек нет.

Страницы основ проверены в Chromium на ширинах 1600, 1280, 1024, 768, 390 и 320 px. Проверены переключение вкладок мышью и клавиатурой, обе темы, одинаковый цвет чисел и единиц, активный пункт меню и доступность всех панелей без JavaScript. Горизонтального переполнения, ошибок загрузки ресурсов и JavaScript нет. Настольные и мобильные скриншоты просмотрены вручную.

## Страница 404

GitHub Pages автоматически отдаёт `404.html` для неизвестных адресов. Пути к ресурсам и на главную начинаются с `/trds-website/`, поэтому работают и для вложенных URL; при смене имени репозитория или домена их нужно обновить. Для обычного локального просмотра с сервером выше откройте папку проекта через родительский сервер либо используйте сервер с маршрутом `/trds-website/`.

Макет — [отредактированный вариант в Paper](https://app.paper.design/file/01M847SMXXTXQ990D316GT3206/p-3-0/CQC-0). Исходная SVG-геометрия сохранена; пять внешних групп добавляют разную глубину движения. Параллакс работает только с мышью и останавливается после успокоения; reduced motion оставляет иллюстрацию и фон статичными. Общая `dot-field.js` добавляет подсветку, притяжение точек и волну по клику. Текст и переход на главную работают без JavaScript.
