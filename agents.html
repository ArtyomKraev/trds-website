Работа с агентами

Репозиторий помогает выбрать существующий компонент и проверить его свойства.

Инструкция для агента

Работай с TRDS: https://github.com/ArtyomKraev/trds-agent-ready

Прочитай START-HERE.md и следуй его инструкции.
Используй компоненты TRDS, их свойства и семантические токены.

Задачу интерфейса я опишу следующим сообщением.

Команды

Выполняйте из папки репозитория

Найти компонент
python3 scripts/kit.py query 'input'
Проверить вариант
python3 scripts/kit.py select Button --props '{"Size":"M","State":"Focused","Label#118:0":"Сохранить"}'
Найти цвет
python3 scripts/kit.py token 'Colors/Surface/Page' --mode Dark
Проверить данные
python3 scripts/kit.py check
